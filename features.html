代码编辑器

写代码的窗口，Dev-C++ 在这一块提供的是“够用”级别的功能，没有智能补全那种花活。

C/C++ 语法高亮

关键字、字符串、注释、数字、预处理指令分色显示。配色可以换，也能自己改每一项的颜色和字体。

函数列表与类浏览

左侧的“类浏览”面板会列出当前文件里的函数、结构体、类成员。点一下就跳到对应位置，几百行的代码不用手动滚。

代码补全

基础的关键字和已输入单词补全，按 Ctrl + Space 触发。它不会分析头文件给出成员函数提示，这一点比不上 Visual Studio 和 CLion。

代码模板

内置常用片段，比如 main 函数骨架、for 循环、头文件保护宏。输入缩写后触发，省去重复敲模板代码。

其它编辑功能

  • 多标签页，可以同时打开多个源文件
  • 括号匹配、自动缩进、行号显示
  • 查找替换支持正则，可跨文件搜索
  • 书签标记，长文件里快速跳转
  • AStyle 一键格式化，统一缩进和空格
  • 撤销栈较深，误删能逐步退回

编译与构建

Dev-C++ 调用自带的 TDM-GCC 完成编译和链接，把两步合成一个“编译”动作，生成的 exe 直接在源文件旁边。

三种运行方式

  • 编译（F9）：只生成 exe，不运行。看编译是否通过时用。
  • 运行（F10）：运行上次编译好的 exe。
  • 编译运行（F11）：编译、链接、运行一次完成。日常最常用。

编译日志

下方“编译日志”窗口显示完整命令、警告和错误。双击错误行能跳到对应代码位置。5.11 的部分提示已汉化，剩下的是 GCC 原始英文输出。

编译选项

在“工具 → 编译选项”里可以加参数，常用的有：

参数作用
-std=c++11按 C++11 标准编译
-std=c++17按 C++17 标准编译（需 GCC 9.2，即 6.3 版）
-O2开启优化，程序跑得更快，调试时别加
-Wall显示所有常见警告，建议一直开着
-g生成调试信息，用 GDB 调试时需要

并行编译（仅 6.3）

6.3 默认开启 MAKE Jobs，多文件工程可以同时编译多个文件，核多的电脑能明显缩短构建时间。5.11 只能一个一个编。

调试功能

内置 GDB，能设断点、单步走、看变量。功能不算强，但定位数组越界、循环写错、变量没赋值这类问题足够。

基本流程

  1. 在行号左侧点一下，出现红色标记，断点设好了
  2. 按 F5 或菜单“调试 → 调试”，程序运行到断点处暂停
  3. 在“调试”面板看局部变量、监视表达式和调用栈
  4. 用“下一步”“单步进入”逐行执行，观察变量变化
  5. 调试结束后点“结束调试”，或按 Ctrl + Alt + F2

能看的调试信息

  • 断点：普通断点、条件断点
  • 变量：局部变量自动列出，也可手动添加监视
  • 调用栈：看清函数是怎么一层层调进来的
  • CPU 窗口：寄存器、反汇编、内存查看
调试前确认编译选项里有 -g，否则断点可能不生效。Release 优化模式（-O2）下变量值可能被优化掉，调试时用默认设置。

工程管理

单个源文件不用建工程，直接编译。多个文件互相调用时才需要建工程，把文件加进同一个项目里统一编译。

新建工程时的模板

  • Console Application：控制台程序，学语法和刷题用这个
  • Windows Application：带窗口的 GUI 程序
  • Static Library：静态库 .a / .lib
  • DLL：动态链接库
  • Empty Project：空工程，自己往里加文件

工程里能做的事

  • 添加、移除源文件和头文件
  • 设置单个文件的编译选项
  • 配置包含目录、库目录和链接库
  • 一键重新编译整个工程
  • 工程文件为 .dev，换电脑拷贝整个文件夹即可

它不原生支持 CMake，也不能像 Visual Studio 那样管理解决方案。工程规模超过几十个文件，维护成本会明显上升。

界面与个性化

中文界面

安装完首次启动时选“简体中文”，菜单和对话框就全是中文。错过了也没关系，在“工具 → 环境选项 → 界面”里可以重新选语言。

可调的项目

  • 编辑器字体、字号、行距
  • 语法高亮的每一项颜色
  • 工具栏显示哪些按钮
  • 快捷键绑定
  • 6.3 提供暗色主题，5.11 只有浅色

做不到的事

这些不是配置问题，是它本身的定位决定的。提前知道能省不少时间。

  • 只支持 Windows：没有 Linux 和 macOS 版本，跨平台项目别用它。
  • 不支持 CMake：主流构建系统用不了，只能用它自己的 .dev 工程。
  • 代码补全弱：没有基于语义的成员提示，大项目写起来费劲。
  • 没有实时错误检查：要编译之后才知道哪行错了。
  • 版本停更：5.11 停在 2016 年，6.3 停在 2021 年，新标准和新系统适配有限。
  • 调试能力一般：多线程调试、内存泄漏检测这些做不了。

如果你的需求超出这些范围，直接用 Visual Studio 社区版（免费）或 CLion 更省事。
