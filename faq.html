使用相关

菜单“文件 → 新建 → 源代码”，或按 Ctrl + N。要写 C 代码就保存成 .c，写 C++ 就保存成 .cpp。
Dev-C++ 默认按 C++ 处理，会自动补 .cpp。想写 C 语言，保存时手动把文件名写成 hello.c，并在保存类型里选 C source files。
