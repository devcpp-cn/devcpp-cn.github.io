Dev-C++ 使用教程

从装好到能写、能编译、能调试的完整流程。每一步都写了会看到什么、点哪里。

本页目录

安装与首次启动 设置简体中文 第一个程序 多文件工程 开启 C++11 / C++17 断点调试 字体、配色和快捷键 卸载与配置备份

安装与首次启动

安装包在下载安装页，5.11 和 6.3 任选一个。安装过程中只有三个地方需要注意：

  • 安装语言只能选 English，装完才能切中文
  • 组件选 Full，不要取消勾选
  • 安装路径不带中文、不带空格，不要装进 C 盘

装完点 Finish 启动，第一次打开会出现语言选择和主题设置，按下一节操作。

设置简体中文

首次启动时设置

  1. 启动后弹出语言选择窗口，下拉框里选 Chinese (Simplified)
  2. 点 OK，进入字体和配色设置，保持默认
  3. 再点 OK，界面就变成中文了

错过了怎么办

菜单“工具 → 环境选项”，找到 Language 下拉框，选 Chinese (Simplified)，点确定，重启 Dev-C++ 生效。

编译时的报错信息有一部分仍是英文。这是 GCC 输出，属正常现象，不是没汉化成功。

第一个程序

Dev-C++ 支持单个源文件直接编译，写练习和刷题不用建工程。下面这套流程走完，你就有第一个能运行的 exe 了。

1）新建源文件

菜单“文件 → 新建 → 源代码”，或按 Ctrl + N。编辑区出现一个空白标签页，默认叫“未命名1”。

2）写代码

C 语言版本：

#include <stdio.h>
#include <stdlib.h>

int main() {
    printf("Hello, Dev-C++!\n");
    system("pause");
    return 0;
}

C++ 版本：

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, Dev-C++!" << endl;
    return 0;
}

3）保存成 .c 或 .cpp

按 Ctrl + S，选一个纯英文路径，比如 D:\code。文件名后缀决定编译器按什么语言处理：

  • hello.c：按 C 语言编译，#include <iostream> 会报错
  • hello.cpp：按 C++ 编译，两种代码都能过

保存时如果文件名没写后缀，Dev-C++ 可能自动补成 .cpp，看清再确认。

4）编译运行

按 F11，或菜单“运行 → 编译运行”。下方日志出现这样的内容就是成功了：

编译成功。0 个错误，0 个警告

随后弹出一个黑色控制台窗口，显示 Hello, Dev-C++!，按任意键关闭。

5）找到生成的 exe

打开源文件所在目录，会看到同名的 exe。双击也能运行，但如果程序里没有暂停语句，窗口会一闪而过。

关于一闪而过：F11 编译运行时，Dev-C++ 会自动帮你暂停，所以看得到输出。单独双击 exe 时不会暂停，程序执行完窗口就关了，这是正常行为，不是程序出错。

多文件工程

代码分成多个 .c / .cpp 文件互相调用时，才需要建工程。单个文件跳过这一节。

  1. 菜单“文件 → 新建 → 项目”，选 Console Application，语言选 C 或 C++
  2. 填工程名，选保存目录，点确定
  3. 工程建好后，右键工程名 → “添加”，把其它源文件加进来
  4. 按 F11 编译整个工程，所有文件一起参与编译链接

工程文件的扩展名是 .dev。换电脑时把整个工程文件夹拷走，打开 .dev 就能继续。

头文件和源文件分开写

多个文件共用的函数声明放在 .h 里，用 #include "xxx.h" 引入。注意引号用于自己写的头文件，尖括号用于标准库。

开启 C++11 / C++17

5.11 开启 C++11

  1. 菜单“工具 → 编译选项”
  2. 切到“设置”标签页
  3. 在“代码生成/优化”里找到语言标准，勾选 C++11 对应的选项
  4. 点确定保存

设置后 auto、范围 for、nullptr、to_string 这些就能用了。改完点确定，再按 F11 重新编译才会生效。

6.3 用 C++17

6.3 自带 GCC 9.2，编译选项里直接选 -std=c++17 即可。也可以手动在“编译时加入以下命令”里填 -std=c++17。

确认标准是否生效

#include <iostream>
int main() {
    std::cout << __cplusplus << std::endl;
    return 0;
}

输出 201103 表示 C++11，201703 表示 C++17，199711 表示还是 C++98。

用 5.11 的 GCC 4.9.2 编译 C++17 代码会报一堆语法错误，这不是代码写错，是编译器版本不够。换 6.3 或升级 MinGW。

断点调试

调试解决的是“代码能编译，但结果不对”的问题。用一段求和的代码演示。

#include <stdio.h>

int main() {
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum += i;
    }
    printf("sum = %d\n", sum);
    return 0;
}

1）设断点

在 printf 那一行的行号左侧点一下，出现红色圆点即设置成功。再点一下取消。

2）开始调试

按 F5，或菜单“运行 → 调试”。程序开始运行，到断点处停住，当前行会高亮。

3）看变量

底部“调试”面板的左侧列出局部变量，能看到 sum 和 i 的当前值。想看表达式就点“添加监视”，输入 sum / 100.0 这类式子。

4）单步执行

  • 下一步：执行当前行，遇到函数调用不进去
  • 单步进入：进入函数内部逐行执行
  • 运行到光标：直接跑到光标所在行

5）结束调试

点“结束调试”或按 Ctrl + Alt + F2。程序会终止，正常关闭调试不会影响源文件。

断点不生效：先确认编译选项里有 -g，再确认断点所在的行是可执行语句（空行、注释行、变量声明行有时停不住）。

字体、配色和快捷键

改字体和字号

“工具 → 编辑器选项 → 显示”，选字体和大小。中文注释显示成方块时，换成“微软雅黑”或“Consolas + 微软雅黑”的组合。

改语法配色

“工具 → 编辑器选项 → 语法”，左边选元素（关键字、字符串、注释等），右边改颜色和粗体。改完点确定立即生效。

改快捷键

“工具 → 快捷键”，找到对应命令，点“修改”，按下新组合键。冲突时它会提示已被占用。

卸载与配置备份

卸载

控制面板 → 程序和功能 → 找到 Dev-C++ → 卸载。卸载程序会问是否保留个人配置，想彻底清干净就选不保留。

备份配置

字体、配色、快捷键这些设置存在安装目录的配置文件里。换电脑前把整个安装目录压缩拷走，解压到同版本上即可复用。

便携版（仅 6.3）

下载 7z 便携包，解压到任意目录，运行 devcpp.exe 就能用，不写注册表。适合放 U 盘或学校机房。
