它是什么

一个给 Windows 用的 C/C++ 编辑器加编译器。写代码、编译、运行、调试都在一个窗口里完成，安装包不到 50MB，老电脑也能跑。

主要特性

该有的都有，多余的没有

Dev-C++ 的功能围绕一件事展开：让单文件代码尽快跑起来。

启动快，占用低

原生 Windows 程序，冷启动通常一两秒。内存占用几十 MB，在 4GB 内存的老笔记本上写代码也不卡。

免费开源

遵循 GPL v2，源代码公开。下载、使用、分发、修改都允许，商用也不需要授权费。

编译器已内置

5.11 自带 TDM-GCC 4.9.2（64 位），6.3 自带 TDM-GCC 9.2。装完直接编译，不用单独装 MinGW，不用配 PATH。

单文件直接编译

一个 .c 或 .cpp 文件就能按 F11 跑起来，不需要新建工程。写算法题、做课后练习，省掉一堆点击。

简体中文界面

首次启动可选简体中文，菜单和对话框都是中文。安装程序本身是英文，装完再切语言。

GDB 调试

支持断点、单步执行、变量监视和调用栈查看。调试命令在“运行”菜单里，按 F5 开始调试，出错时能直接看到变量值。

编辑器够用：语法高亮、函数列表、代码模板、AStyle 格式化

支持 C/C++ 语法高亮、类浏览和函数列表。内置常用代码片段和基础的单词补全（Ctrl+Space），AStyle 一键排版，长代码不会写成一团。还支持自定义快捷键、字体、配色，配置项不多，看得懂也改得动。

快速上手

从安装到跑出第一行输出

总共五步，第一次装大约 3 分钟。

1

安装

双击安装包，语言选 English，组件选 Full，安装路径不要带中文，也别装进系统盘。

2

切成简体中文

首次启动会提示选择语言，选“简体中文”。字体和配色保持默认，点 OK。

3

新建源文件

菜单“文件 → 新建 → 源代码”，或按 Ctrl + N。保存时记得把后缀写成 .c 或 .cpp。

4

写代码并保存

输入代码，按 Ctrl + S 保存到英文路径下。

5

编译运行

按 F11，或菜单“运行 → 编译运行”。下方日志显示“编译成功”后，程序窗口会自动弹出。

常见问题

新手最常卡住的几件事

完整问题在常见问题页，这里先列四条。

5.11 可以在 Windows XP、Vista、7、8、8.1、10、11 上运行。6.3 需要 Windows 7 及以上。它没有 Linux 和 macOS 版本。
双击 exe 运行时，程序执行完就退出，窗口自然关闭。用 F11 编译运行不会闪退。如果直接运行 exe，可在 return 0 前加 system("pause");，并 #include <stdlib.h>。
九成是路径问题。源文件放在中文名文件夹或桌面路径里，编译器找不到。把文件挪到 D:\code 这类纯英文、无空格的目录再编译。
5.11 自带的 GCC 4.9.2 最高支持 C++11，且要在编译选项里手动加 -std=c++11。要用 C++17，装 6.3（GCC 9.2），或在工具 → 编译选项里换成新版 MinGW。
